Let’s start applying what we have learned so far by setting up your company in Chat-Accounting.

If you have not downloaded Chat-Accounting, you can download it from the [Chat-Accounting website](https://chataccounting.vercel.app/#download).

## Setup Instance

When you open Chat-Accounting, you’ll be presented two options: **New File** and **Existing File**. If this is the first time you are opening Chat-Accounting, click on **New File**.

Now select an appropriate location where you want to store the file and give it a name.

![New File](/images/setting-up/new-file.png)

<Tip>
File Location Chat-Accounting stores all your company data and transactions on a local `.db` file on your computer.

You can change the location of this `.db` file. If you have done so you can find it again by selecting the **Existing File** option.
</Tip>

Now, enter your Business Name, Business Email and Country Information. This will help set up the correct Chart of Accounts based on your country.

![Setup Wizard](/images/setting-up/setup-wizard.png)

<Tip>
Chart of Accounts If you don't find the Chart of Accounts of your country, you can select the **Standard Chart of Accounts**.
</Tip>

---

Congratulations! You now have a company set up on Chat-Accounting.

You can now move onto the next step to create some initial entries before you can start recording your invoices and transactions.
